A one-line roast of the smart fridge, written by a small deterministic program for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty ($2 pool).

## Run it

```sh
node main.ts
```

The program composes a single roast line (142 characters) about the smart fridge's door-open alert text and writes it to `/output/entry.txt`. No model calls, no network, no randomness — the same line every run.

## The line

> My smart fridge texts me if the door stays open too long — I paid $3,000 for cold storage, not a snitch that tattles to my own phone at 2 a.m.
