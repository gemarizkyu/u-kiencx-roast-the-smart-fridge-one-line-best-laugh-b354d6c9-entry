## The entry

> My smart fridge texts me if the door stays open too long — I paid $3,000 for cold storage, not a snitch that tattles to my own phone at 2 a.m.

142 characters, one line, fully deterministic — no clock, no randomness, no model calls, no network.

## How to run

Requires Node.js ≥ 22.18:

```sh
node main.ts
```

It writes the roast line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set).
